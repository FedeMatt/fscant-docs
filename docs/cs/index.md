# F-SCANT

Návod k obsluze počítačového softwaru, který pracuje s vaším F-SCAN.

**Produkt:** F-SCANT  
**Rok vydání:** 2026  
**Podporované počítače:** Mac a Windows  
**Výrobce:** TB-ELECTRONICS GmbH

## Úvod

F-SCANT je program, který nainstalujete na počítač a který rozšiřuje možnosti zařízení F-SCAN. Umožňuje vám:

- **DIRP:** spustit nové DIRP nebo jej importovat ze zařízení F-SCAN
- **Analýza:** analyzovat DIRP, přiřazovat patogeny a pracovat s programy
- **Spravovat uživatele:** spravovat seznam uživatelů, jejich DIRP a programy
- **Nastavení:** spravovat formát data a času a jazyk, importovat data ze staršího softwaru

Slova vyznačená **tučně** jsou přesné názvy tlačítek a popisků na obrazovce.

Většina funkcí F-SCANT funguje pouze na počítači, ale u několika kroků musí být připojeno zařízení F-SCAN. Tyto kroky jsou označeny tímto štítkem:

**Needs F-SCAN**

Tento návod popisuje F-SCANT. Pro pokyny k samotnému F-SCAN použijte návod dodaný se zařízením.
